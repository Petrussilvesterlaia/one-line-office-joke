A one-line office joke for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty: the boss calls the team a family, but the only inheritance so far is his 6 p.m. "quick question".

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (one line, at most 200 characters, validated before writing and verified by reading it back).
